## 基本

| 項目 | 値 |
|---|---|
| デザインのツール | 【XD / Photoshop】（ページごとに違うときは下の「ページ」に書く） |
| PCのアートボードの幅 | 【1440】px |
| スマホのアートボードの幅 | 【390】px |
| コンテンツの最大幅 | 【1200】px |
| 左右の余白 | PC【40】px ／ スマホ【20】px |
| PCとスマホを切り替える幅 | 【768】px |
| メニューの形を切り替える幅 | 【1024】px |

## 色

| 名前（CSS変数にする） | 値 | 使う場所 |
|---|---|---|
| `--color-main` | 【#005bcc】 | 【ボタン・リンク】 |
| `--color-text` | 【#222222】 | 【本文】 |
| `--color-bg` | 【#ffffff】 | 【背景】 |
| `--color-border` | 【#dddddd】 | 【罫線】 |

## 余白

- 使う値：【8 / 16 / 24 / 40 / 64 / 96】px
- セクションの間：PC【120】px ／ スマホ【64】px
- 見出しと本文の間：PC【40】px ／ スマホ【24】px
