## 2. 書き直しで入ったずれ

D のあと、静的 HTML（`dist/`）と WordPress の表示を並べて見比べる。見つけたものを1行ずつ書く。

| # | 種類 | 場所（部品の名前） | 内容 | 直した人（Claude / 人） |
|---|---|---|---|---|
| 1 | 【見た目 / マークアップ / エスケープ漏れ / CSS・JS の置き場所 / その他】 | | | |

確かめる観点：

- 見た目：余白・文字サイズ・画面の幅を変えたときの崩れ
- マークアップ：見出しの順番、`alt`、`aria-*` が、静的 HTML から変わっていないか
- エスケープ：WordPress の値を出す所に、`esc_html()` `esc_url()` `esc_attr()` が付いているか（`.claude/rules/wordpress.md`）
- CSS・JS：静的（`src/assets/`）とテーマの2か所に、同じファイルができていないか
